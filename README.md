# Competitive Programming Solutions

This repository is a personal collection of solutions to problems from various online judges and competitive programming platforms.

## Structure

The repository is organized by platform, with each platform having its own top-level directory:

- **AtCoder:** Solutions for AtCoder contests.
- **CodeChef:** Solutions for CodeChef problems.
- **Codeforces:** Solutions for Codeforces rounds and problems.
- **HackerEarth:** Solutions for HackerEarth challenges.
- **LeetCode:** Solutions for LeetCode problems.
- **LightOJ:** Solutions for LightOJ problems.
- **UVa:** Solutions for UVa Online Judge problems.
- **Other Platforms:** Solutions from other platforms, like HackerCup.
- **Templates:** Reusable code templates for common algorithms and data structures.

Inside each platform directory, solutions are usually further organized by contest, problem number, or category.

## Navigation

To find a specific solution, navigate to the respective platform's directory and then look for the contest or problem ID. Most solution files are named according to the problem ID (e.g., `118D.cpp`, `abc185_e.cpp`).

## Languages

Solutions are primarily written in C++, with some in Java or Python. The file extension indicates the language used.

## Disclaimer

These solutions were written for practice and learning. While they are believed to be correct for the specific problems they address, they may not always represent the most optimal or idiomatic way to solve them.
